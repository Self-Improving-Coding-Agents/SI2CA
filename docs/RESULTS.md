# Experiment results

The [README Results section](../README.md#results) reports the main SJ/SL comparison on SWE-bench Verified and Pro, and DeepSWE Table 2, including resolve rates and mean/median/P90 turns.

Pro uses the author's corrected **731-task** table; Verified uses **500 tasks**, and DeepSWE uses **113 tasks**. See the README for source and reproducibility notes.

Archived results, trajectories, table-verification scripts and the viewer live in [SI2CA-Visualization](https://github.com/Self-Improving-Coding-Agents/SI2CA-Visualization); they are not required to run new experiments from this repository.
